# Announcement

## GitHub Release

`Community Alpha 1.0`

Публичный alpha-релиз «Печатай с Круассаном» уже онлайн: [type.profy.top](https://type.profy.top)

Что внутри:
- веб-тренажер слепой печати на русском без лендинга и маркетинговой обвязки
- регистрация, сохранение прогресса и возврат позже с того же аккаунта
- первая неделя курса с выровненной прогрессией
- mobile и desktop flow
- product analytics через Plausible без отправки персональных данных

Что проверено:
- `typecheck`
- production `build`
- smoke e2e для desktop и mobile
- live deploy на `type.profy.top`

Что пока вне scope:
- лендинг
- соцлогин
- платные функции
- админка
- email-функции
- восстановление пароля

Если что-то ломается или хочется предложить улучшение, приносите issue в репозиторий.
